# TCET MUN 2026

Official website of the TCET MUN Committee for TCET MUN 2026.

## About

TCET MUN 2026 is the official Model United Nations conference
organized by the TCET MUN Committee at Thakur College of
Engineering and Technology.

This repository contains the source code for the official
TCET MUN 2026 website.

## Website Features

- Home
- Committees
- Events
- Our Team
- Gallery
- Registration
- Contact
- Responsive design

## Tech Stack

- CSS3
